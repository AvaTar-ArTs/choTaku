## Provenance

- Generated during the choTaku visual-language expansion.
- Source guidance: docs/visual-reference-template-atlas-2026-08-15.md, docs/visual-language-research-2026-08-15.md, and the AvatarArts creative-history corpus.
- These are concept references and layout exemplars, not canonical story assets.
- Text inside generated images is illustrative; production lettering should use choTaku text regions and typography manifests.
- The compressed JPEGs are repository-friendly derivatives of the generated PNGs. The originals remain available through the generation session/library.

## Intended use

Use these images to:

1. compare layout families before selecting a LayoutContract;
2. brief an image or composition provider;
3. test focal-cell, reading-order, gutter, and text-safe-zone validators;
4. develop style references without locking the semantic storyworld to one genre;
5. demonstrate how one narrative can project into multiple publication formats.
